# Aviso de atribución de terceros

Nueve skills de este paquete se adaptaron de **Construction Agent Skills**, creado por **Constructelligence**: [repositorio de origen](https://github.com/constructelligence-lab/construction-agent-skills/tree/f05ffdf70b650582a4a12181d6fedcc9b3ae56f1) en la revisión `f05ffdf70b650582a4a12181d6fedcc9b3ae56f1`. Licencia: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

Skills derivadas: `programme-and-sequencing-options`, `mep-coordination-clash-triage`, `takeoff-review-checklist`, `unit-rate-sanity-check`, `lookahead-constraint-sweep`, `daily-report-from-notes`, `jsha-from-task-description`, `rfi-drafting` y `contract-risk-review`.

Se conservaron los flujos fuente. Se adaptaron las descripciones a español y a un límite compatible con Claude.ai; también se añadió una indicación de responder en el idioma del usuario y atribución con enlace. Las tres skills `mexico-*` son nuevas para este paquete y citan fuentes oficiales en sus carpetas `references/`.

El repositorio fuente indica que sus skills son borradores, se proporcionan “as is” y no sustituyen a una persona competente, ingeniero, contrato o abogado. Esa limitación aplica también a las copias y adaptaciones de este paquete.
